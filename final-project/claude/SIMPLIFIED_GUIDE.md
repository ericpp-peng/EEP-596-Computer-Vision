# 簡化版快速使用指南

## 🎯 專案狀態

本專案目前實作**姿勢分析簡化版**，專注於以下核心功能：
- ✅ 人物骨架偵測與視覺化
- ✅ 關鍵角度計算與分析
- ✅ 專業姿勢對比與評分
- ✅ 球場線條繪製（可選）

## ⚡ 快速開始（3 步驟）

### 步驟 1: 球場標定（可選，一次性）

如果需要顯示球場線條：

```bash
python court_calibration.py
```

依照提示點選球場 4 個角點，完成後會生成 `court_corners.pkl` 檔案。

> 💡 如果跳過此步驟，仍可執行姿勢分析，只是不會顯示球場線條。

### 步驟 2: 執行姿勢分析

```bash
python pose_analysis.py
```

程式會自動：
1. 載入 YOLO Pose 模型
2. 偵測影片中的人物骨架
3. 計算關鍵角度（肩膀、手肘、髖部）
4. 與專業標準比較並評分
5. 輸出分析影片

### 步驟 3: 查看結果

```bash
open pose_analysis_output.mp4
```

或直接在 Finder 中打開檔案。

## 🔧 設定調整

### 修改影片路徑

編輯 `pose_analysis.py` 第 24 行：

```python
VIDEO_PATH = "你的影片.mp4"
```

### 調整專業標準角度

編輯 `pose_analysis.py` 第 31-35 行：

```python
PRO_STANDARDS = {
    "shoulder_angle": 145,  # 調整這個值
    "elbow_angle": 165,     # 調整這個值
    "hip_angle": 170,       # 調整這個值
}
```

### 切換 YOLO 模型

編輯 `pose_analysis.py` 第 28 行：

```python
POSE_MODEL_PATH = "yolov8n-pose.pt"  # 或 "yolo11n-pose.pt"
```

## 🐛 疑難排解

### Q1: 找不到影片檔案

**錯誤訊息**: `❌ 無法開啟影片: 20250711_short.mp4`

**解決方法**: 
- 確認影片檔案在同一目錄下
- 或修改 `VIDEO_PATH` 為完整路徑

### Q2: 模型下載失敗

**錯誤訊息**: `Failed to download model`

**解決方法**:
```bash
# 手動下載模型
python -c "from ultralytics import YOLO; YOLO('yolo11n-pose.pt')"
```

### Q3: 沒有偵測到人物

**可能原因**:
- 人物在畫面中太小
- 光線太暗或過曝

**解決方法**:
- 調整影片品質
- 或降低置信度閾值

### Q4: 角度計算異常

**現象**: 角度顯示 0° 或超過 180°

**原因**: 關鍵點偵測失敗

**解決方法**: 正常現象，該幀會跳過分析
